# diffusion_deploy (Resource)

Deploys Ansible roles to remote hosts using the diffusion molecule container.

It fetches `diffusion.lock` from each `role_sources` entry, merges dependency constraints, and runs `ansible-playbook` inside the container. Roles and collections are installed **inside the container** — nothing is downloaded to the machine running Terraform.

## How It Works

1. For each role source, the provider fetches `diffusion.lock` from the remote repository
2. It merges all dependency constraints (Python version, collections, tools)
3. An Ansible inventory is built from `hosts`, `groups`, and `variables`
4. When `playbook` is omitted, a playbook is auto-generated that applies each role to its `apply_to` hosts pattern (default: `"all"`)
5. `diffusion deploy` runs `ansible-playbook` inside the molecule container
6. State (`~/.diffusion/state`) is written on each remote host for tracking

## Idempotency

Use `skip_if_succeeded_within` to avoid re-deploying when inputs haven't changed:

```terraform
resource "diffusion_deploy" "app" {
  # ...
  skip_if_succeeded_within = "24h"
}
```

If the last deployment succeeded within the specified period and all inputs are identical, the deploy is skipped.

## Example Usage

### Basic — Single Git Role

```terraform
resource "diffusion_deploy" "nginx" {
  role_sources = [
    {
      scm     = "git"
      url     = "https://github.com/org/ansible-role-nginx.git"
      version = "v2.1.0"
      name    = "nginx"
    },
  ]

  hosts = {
    "web-01" = {
      vars = {
        ansible_host            = "192.168.1.10"
        ansible_user            = "deploy"
        ansible_ssh_private_key_file = "~/.ssh/id_ed25519"
      }
    }
  }

  groups = {
    webservers = ["web-01"]
  }
}
```

### Multiple Roles with Galaxy

```terraform
resource "diffusion_deploy" "stack" {
  role_sources = [
    {
      scm     = "git"
      url     = "https://github.com/org/ansible-role-app.git"
      version = "main"
      name    = "app"
      apply_to = "appservers"
    },
    {
      scm     = "galaxy"
      galaxy  = "geerlingguy.docker"
      version = ">=7.0.0"
      apply_to = "all"
    },
  ]

  hosts = {
    "app-01" = {
      vars = {
        ansible_host = "10.0.1.10"
        ansible_user = "ubuntu"
      }
    }
    "app-02" = {
      vars = {
        ansible_host = "10.0.1.11"
        ansible_user = "ubuntu"
      }
    }
  }

  groups = {
    appservers = ["app-01", "app-02"]
  }

  variables = {
    env         = "production"
    app_version = "2.3.0"
  }

  extra_vars = {
    force_restart = "true"
  }

  skip_if_succeeded_within = "12h"
}
```

### With Custom Playbook

```terraform
resource "diffusion_deploy" "custom" {
  role_sources = [
    {
      scm     = "git"
      url     = "https://github.com/org/ansible-role-myapp.git"
      version = "v1.0.0"
    },
  ]

  playbook = "${path.module}/playbooks/deploy.yml"

  hosts = {
    "server-01" = {
      vars = {
        ansible_host = aws_instance.app.public_ip
        ansible_user = "ubuntu"
      }
    }
  }
}
```

### With AWS EC2

```terraform
resource "aws_instance" "app" {
  ami           = data.aws_ami.ubuntu.id
  instance_type = "t3.medium"
  key_name      = var.key_name
}

resource "diffusion_deploy" "app" {
  role_sources = [
    {
      scm     = "git"
      url     = "https://github.com/org/ansible-role-app.git"
      version = "v1.0.0"
    },
  ]

  hosts = {
    "app-01" = {
      vars = {
        ansible_host            = aws_instance.app.public_ip
        ansible_user            = "ubuntu"
        ansible_ssh_private_key_file = var.ssh_key_path
        ansible_ssh_common_args = "-o StrictHostKeyChecking=no"
      }
    }
  }

  # Wait for instance to be SSH-reachable
  host_wait_initial_delay = "30s"
  host_wait_timeout       = "5m"

  skip_if_succeeded_within = "1h"
}
```

## Schema

### Required

- `role_sources` (List of Object) List of remote role repositories to fetch `diffusion.lock` from. (see [below for nested schema](#nestedatt--role_sources))

### Optional

- `playbook` (String) Path to an Ansible playbook (relative to the Terraform working directory or absolute). When omitted, a playbook is auto-generated from `role_sources`.
- `hosts` (Map of Object) Map of hostname → host variables. (see [below for nested schema](#nestedatt--hosts))
- `groups` (Map of List of String) Map of group name → list of host names.
- `variables` (Map of String) Global inventory variables applied to the `all` group.
- `extra_vars` (Map of String) Extra variables passed to `ansible-playbook --extra-vars`.
- `skip_if_succeeded_within` (String) Skip re-deploy if the last run succeeded within this period and inputs are identical. Go duration string (e.g. `"24h"`). Empty means always deploy.
- `host_wait_initial_delay` (String) Override provider default initial delay before first host probe (Go duration).
- `host_wait_interval` (String) Override provider default interval between host probes (Go duration).
- `host_wait_timeout` (String) Override provider default hard deadline for host reachability (Go duration).

### Read-Only

- `run_id` (String) SHA-256 hash of all deploy inputs. Stable for identical plans.
- `last_deployed` (String) RFC3339 timestamp of the last successful deploy.
- `merged_lock_hash` (String) Hash of the merged `diffusion.lock` across all role sources.
- `inventory_rendered` (String) The rendered Ansible YAML inventory (for inspection/debugging).
