# diffusion_inventory (Data Source)

Renders an Ansible YAML inventory from the provided hosts, groups, and variables **without triggering any deployment**. Useful for:

- Inspecting and debugging inventory before deploying
- Passing the rendered YAML to other resources or outputs
- Validating inventory structure in CI/CD

## Example Usage

### Basic Inventory

```terraform
data "diffusion_inventory" "preview" {
  hosts = {
    "web-01" = {
      vars = {
        ansible_host = "192.168.1.10"
        ansible_user = "deploy"
      }
    }
    "web-02" = {
      vars = {
        ansible_host = "192.168.1.11"
        ansible_user = "deploy"
      }
    }
  }

  groups = {
    webservers = ["web-01", "web-02"]
  }

  variables = {
    env         = "production"
    app_version = "1.5.0"
  }
}

output "inventory" {
  value = data.diffusion_inventory.preview.rendered
}
```

### Dynamic Inventory from AWS Instances

```terraform
resource "aws_instance" "app" {
  count         = 3
  ami           = data.aws_ami.ubuntu.id
  instance_type = "t3.micro"
  key_name      = var.key_name
}

data "diffusion_inventory" "dynamic" {
  hosts = {
    for idx, inst in aws_instance.app : "app-${format("%02d", idx + 1)}" => {
      vars = {
        ansible_host = inst.public_ip
        ansible_user = "ubuntu"
      }
    }
  }

  groups = {
    appservers = [for idx in range(length(aws_instance.app)) : "app-${format("%02d", idx + 1)}"]
  }

  variables = {
    ansible_python_interpreter = "/usr/bin/python3"
  }
}
```

### Output Format

The `rendered` attribute contains a valid Ansible YAML inventory:

```yaml
all:
  hosts:
    web-01:
      ansible_host: "192.168.1.10"
      ansible_user: "deploy"
    web-02:
      ansible_host: "192.168.1.11"
      ansible_user: "deploy"
  children:
    webservers:
      hosts:
        web-01: {}
        web-02: {}
  vars:
    app_version: "1.5.0"
    env: "production"
```
