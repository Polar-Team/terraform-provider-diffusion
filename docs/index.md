# Diffusion Provider

The **diffusion** provider deploys Ansible roles to remote hosts using the [Diffusion](https://github.com/Polar-Team/diffusion) molecule container. It fetches `diffusion.lock` from remote role repositories, merges dependency constraints, downloads collections and roles, and executes `ansible-playbook` inside the container.

The `diffusion` CLI binary must be installed on the machine running Terraform/OpenTofu.

## How It Works

1. You specify **role sources** (Git repos or Galaxy roles) that contain a `diffusion.lock`
2. The provider fetches lock files and merges dependency constraints
3. It builds an Ansible inventory from your `hosts`, `groups`, and `variables`
4. It runs `diffusion deploy` which pulls the molecule container, installs roles/collections inside it, and runs `ansible-playbook`
5. State is written to `~/.diffusion/state` on each remote host for idempotency tracking

## Requirements

- [Diffusion CLI](https://github.com/Polar-Team/diffusion) installed and on `$PATH`
- Docker running (the provider uses the molecule container for execution)
- Network access to the target hosts (SSH)
- Network access to role source repositories (Git/Galaxy)

## Example Usage

```terraform
terraform {
  required_providers {
    diffusion = {
      source  = "Polar-Team/diffusion"
      version = "~> 0.1"
    }
  }
}

provider "diffusion" {
  registry_server = "ghcr.io"
  container_tag   = "latest-amd64"
}

resource "diffusion_deploy" "app" {
  role_sources = [
    {
      scm     = "git"
      url     = "https://github.com/org/ansible-role-myapp.git"
      version = "v1.0.0"
    },
  ]

  hosts = {
    "web-01" = {
      vars = {
        ansible_host = "192.168.1.10"
        ansible_user = "deploy"
      }
    }
  }

  skip_if_succeeded_within = "24h"
}
```

## Authentication

### Container Registry

The provider pulls the molecule container from a registry. For public registries (GHCR), no additional auth is needed. For private registries, configure the `registry_provider`:

- `Public` — No authentication (default)
- `YC` — Yandex Cloud Container Registry
- `AWS` — Amazon ECR
- `GCP` — Google Container Registry

### HashiCorp Vault

Credentials for private artifact sources (Galaxy servers, Git repos) can be fetched from HashiCorp Vault:

```terraform
provider "diffusion" {
  vault_addr  = "https://vault.example.com"
  vault_token = var.vault_token

  artifact_source {
    name               = "private-galaxy"
    url                = "https://galaxy.internal.com"
    type               = "galaxy"
    use_vault          = true
    vault_path         = "secret"
    vault_secret_name  = "galaxy-creds"
    vault_username_field = "username"
    vault_token_field    = "token"
  }
}
```

Vault credentials can also be supplied via environment variables `VAULT_ADDR` and `VAULT_TOKEN`.
